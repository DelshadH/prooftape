# @prooftape/core

Canonicalization, observation comparison, isolated Git revision recording, and
safe reproduction generation for ProofTape.

This package is an early `0.1.0-alpha.1` release for Node.js 22.15 or newer. It
is an internal building block of the `prooftape` CLI; its JavaScript API is not
the primary supported product surface.

Observation authenticity is not established against code under test. Read the
[trust boundary](https://github.com/DelshadH/prooftape/blob/main/docs/security-model.md)
before relying on an artifact.
